## 2025-05-05 - Logarithmic Doubling for Byte Slice Generation
**Learning:** Generating large, repeated or cyclic deterministic byte payloads (like PRBS-like test sequences or basic padding) using a `for i := range` loop is a significant CPU bottleneck in Go. Precalculating the base repeating pattern and duplicating it using logarithmic doubling with `copy()` can improve performance dramatically (e.g. 3-4x faster for 1MB slices).
**Action:** When filling byte slices of 1MB or more with repeating content, always use logarithmic doubling (`p[0] = b; for i := 1; i < len(p); i *= 2 { copy(p[i:], p[:i]) }`) instead of iterating over every byte. For cyclic patterns (like modulo math), initialize the base pattern and then double. Do not apply this to small slices as the overhead outweighs the benefit.
